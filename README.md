<h1><a href="https://github.com/prsilvaa/Cybersecurity-Project">Cybersecurity Assessment Tool</a></h1>

<h2>Project Objective</h2>

<p>Develop a user-friendly cybersecurity website designed to help home users and non-technical individuals understand their digital security and identify potential weaknesses in their devices. The platform brings together a range of cybersecurity tools, presenting findings through clear risk indicators and practical recommendations without requiring specialist technical knowledge.</p>

<h2>My Role and Responsibilities</h2>

<ul>
    <li><strong>Project Manager</strong> – Coordinated the group project, supported task allocation, monitored progress, and helped organise development using the P3 Express project management framework.</li>
    <li><strong>Vulnerability Tool Developer</strong> – Developed the Python-based device vulnerability assessment tool to collect operating system information and check firewall and antivirus status.</li>
    <li><strong>Risk Assessment</strong> – Implemented rule-based risk classification to categorise device security as Low, Medium, or High risk based on the assessment results.</li>
    <li><strong>Report Generation</strong> – Developed automated report generation to present findings and provide practical security recommendations in understandable language.</li>
    <li><strong>Backend Integration</strong> – Connected the vulnerability assessment functionality to the Flask backend so the website could request checks and display the results.</li>
</ul>

<h2>Tools and Technologies Used</h2>

<ul>
    <li><strong>Python</strong> – Developed the device security checks, risk classification, and report generation functionality.</li>
    <li><strong>Flask</strong> – Connected the website interface to the backend security tools through API endpoints.</li>
    <li><strong>Operating System Libraries</strong> – Collected operating system information and supported platform-specific security checks.</li>
    <li><strong>Subprocess</strong> – Executed operating system commands to retrieve firewall and antivirus status where supported.</li>
    <li><strong>P3 Express and MoSCoW</strong> – Supported project management, task prioritisation, and requirements planning.</li>
</ul>

<h2>Key Features</h2>

<ul>
    <li><strong>Device Security Assessment</strong> – Collects operating system details and checks firewall and antivirus status where supported.</li>
    <li><strong>Automated Risk Classification</strong> – Assigns a risk level using predefined rules based on the collected security information.</li>
    <li><strong>Security Report Generation</strong> – Produces a readable report containing assessment findings and recommendations.</li>
    <li><strong>Network Security Assessment</strong> – Integrates network scanning functionality developed as part of the wider group project.</li>
    <li><strong>Accessible Security Guidance</strong> – Presents security information in plain language to help non-technical users understand potential risks.</li>
</ul>

<h2>Project Outcome</h2>

<p>NetWise delivered a centralised cybersecurity website designed to make basic security assessments more accessible to home users and non-technical individuals. The platform integrated multiple tools, including network scanning, password security checks, phishing awareness activities, and device vulnerability assessment.</p>

<p>My main technical contribution was developing the device vulnerability assessment tool, which collects operating system information, checks firewall and antivirus status where supported, calculates a rule-based risk level, and generates a report with security recommendations. As Project Manager, I also supported team coordination, task management, and delivery throughout the project lifecycle.</p>

<p>The project strengthened my technical and organisational skills by combining hands-on cybersecurity development with responsibility for coordinating a collaborative software project.</p>

<h2>Ethical and Responsible Use</h2>

<p>NetWise was designed to support authorised security assessments and improve cybersecurity awareness. The platform focuses on basic security checks and educational recommendations rather than intrusive testing or exploitation.</p>
